One-time setup

This app reads your Gmail through your own Google Cloud project. It only ever asks for read-only access. Setup takes about 10 minutes.

  1. Go to Google Cloud Console and create a project (any name).
  2. Open Gmail API and click Enable.
  3. Open Google Auth Platform (OAuth consent screen). Choose External, fill in an app name and your email, and leave it in Testing.
  4. Under Audience → Test users, add your own Gmail address.
  5. Under Clients, create a client of type Desktop app, then download its JSON.
  6. Rename the file to credentials.json and put it in the project folder (next to run.ps1).
  7. Reload this page.
